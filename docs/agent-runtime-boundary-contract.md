# Agent 執行邊界與機密連線通用契約 (Agent Runtime Boundary & Secret Contract)

本文檔定義專案開發中 Host Agent（宿主機代理人）與 Container Agent（容器內代理人）的執行邊界、機密存取規範與網路連線契約。所有專案 Agent 必須嚴格遵循此契約，消除跨邊界誤用與憑證探索摩擦。

---

## 面向一：給 Host Agent（宿主機代理人）

> **核心定位**：你是「代碼編輯與任務調度者」，不是「執行期環境」。

1. **禁止在宿主機執行整合測試**：宿主機環境缺少容器內專屬路徑（如 `/var/opt/...`、`/etc/opt/...`），亦無法解析容器內部網域名稱（如 `dev-postgres`）。禁止在宿主 shell 直接執行依賴資料庫、快取或跨服務通訊之整合測試。
2. **禁止探查或猜測密鑰明文**：嚴禁執行 `cat .env`、搜尋機密檔案或嘗試在宿主機偽造憑證。遭遇平台安全分類器或權限阻擋為標準防禦行為，切勿嘗試繞過。
3. **所有執行一律調度至容器**：代碼編輯於宿主工作區完成後，測試執行、服務啟動與資料庫遷移一律透過 `podman exec` 派發進容器內部執行：
   ```bash
   podman exec -w /workspace <CONTAINER_NAME> <COMMAND>
   ```

---

## 面向二：給 Container Agent（容器內代理人）

> **核心定位**：你是「隔離環境內的執行與驗證者」，所有憑證、依賴與內部網路皆已就緒。

1. **信任並使用 `*_FILE` 契約**：所有資料庫與服務憑證已由平台唯讀掛載完畢，SDK 與應用程式會自動由 `*_FILE` 環境變數指定之路徑讀取密鑰，開箱即用，無需手動配置。
2. **嚴禁暴露或寫入憑證材料**：機密目錄宣告為唯讀（`:ro`）。嚴禁於日誌、錯誤訊息或標準輸出印出金鑰明文，嚴禁將密鑰寫入原始碼或靜態檔案。
3. **禁止指向 127.0.0.1 或 localhost**：微服務間依賴容器網路內部別名（例如 `dev-postgres:5432`）互聯，禁止改連 `127.0.0.1` 或 `localhost`。
4. **零阻塞就地驗收**：容器內部即為真實運行環境，直接於 `/workspace` 執行測試與驗收腳本即可。
